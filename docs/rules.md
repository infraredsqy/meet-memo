# meeting · 纪律

> 动手之前读这一份：测试、文档、代码注释三条。条文与判例各归一处，同一个问题被讲第二遍就长一条。

## 测试

- 提交前跑全量：服务端 `python -m pytest -q`（含慢档）；前端 `cd web && npm test`、`npm run typecheck`、`npm run build`。
- **打模型端点花的是机主的 token，跑代码只耗电，两回事。**`tests/` 里的用例一律注入假件，
  一条真实模型端点请求都不发；出口有一道 autouse 兜底（`tests/conftest.py` 的 `_no_real_model_call`：
  本机回环放行，其余拦下）。
- 真实端点、真实会议素材的验证写成**一次性脚本**：跑一次、看完证据就完事，不进 `tests/`，
  也不随仓库保留。
- **要便宜且确定**：单条用例 ≤ 5 秒、单个测试文件 ≤ 10 秒；等真墙钟的进慢档（`pytest.mark.slow`）。
  归位判据与慢档清单的现算命令在 `docs/service.md`。
- **不写自证式测试**：import 生产常量再断言「它出现在输出里」、断言常量 == 字面量的纯复制
  一律不收（API 契约的冻结表是唯一例外）；同一事实只在一个测试里钉死，镜像测试删较弱一方。
- 测试数据一律用合成样本：真实会议转写、真实用户名与个人目录不进仓库。

## 文档

- **文档只写现状与判据，不写过程物**：变更史、「本轮实测」读数、完成标记一律不进 md——git 是日志。
  能现算的数不存：用例数用 `pytest --collect-only` 现算，契约样本数现数。
- **一处事实只住一处**：改一处不用动第二处。镜像与速查一律改成指向正本的指针——契约样本与
  掩码在 `contract/README.md`，界面口径在 `docs/ui-design.md`，配置键在 `docs/service.md`，
  心跳判据在 `docs/state.md`。
- **README 只当门面**：是什么、怎么装起、几条命令、开发入口、联系。键表、退出码、log 轮转、
  协议细节一律住 `docs/` 的正本，README 不抄第二份。
- **指针存种子不存坐标**：跨文档只指到文件；条款级引用只用稳定编号（契约小节号、R 号、意图条号——
  契约那套小节号由 `docs/contract.md` 自己声明为稳定编号），不写「第 X 章 / 第 X 节」、不写行号。
- **哈希与删除叙事不进 md**：commit 哈希、「已随 X 删除 / 已从 Y 换掉」的考古、被否方案的
  论证过程一律不进——git 是日志。
- 目录根上的路牌叫 `AGENTS.md`：一句话说这个目录是什么，加一棵 tree，一行一处说清「是什么 ＋
  什么时候看」；正文不进路牌。

## 代码注释

- **注释四不写**：文档坐标（行号、没人声明为稳定的章号）、实测读数（「本机实测 X 秒 / 余量 Y」）、
  审查轮次与授权叙事（「第 N 轮审查」「用户后来定为硬要求」）、复述下一行代码的旁白——一律不进。
- **注释只装旁读不出的判据**：取值为什么必须大于 / 小于某个量、偶发失败的根因、「这两处必须
  同源同值」的约束。能被旁边代码或类型说清的，删。
