# meeting · 设计意图

> 这份文档写的是**为什么**：为什么要有这个软件、为什么它该长成这样、为什么某些做法会让机主难受。
> 不写"要做什么"（`docs/requirements.md`），不写"怎么做"（节点 spec）。往这里塞待办或实现细节，它就会过时、就会被当成判尺乱用。
> **只在机主的想法本身变化时修改。** 节点完成、方案调整、实现细节变动，都不改这里。

## 总规矩：怎么判断一句话是不是"用户真需求"

> 仓库里任何"不做 / 必须这么做"的说法，如果在这份文档里找不到对应的理由，一律按「AI 自定、待复核」处理。
> 反过来：凡是本文写下的意图，与它冲突的既有设计、契约、注释、文档一律以本文为准——要改就改那些，不要改本文去迁就代码。

用法：手上有个待办或一句"必须/不做"，先在这里找对应条目；找到了，看"我们要什么"与"推翻"两条都对得上就照做，对不上按待复核处理；**找不到对应条目**，默认它是"AI 自定"的，不要拿它去挡新需求，也不要把新需求说成"违背了既定设计"。

这个项目里出现过太多"AI 没跟机主对齐、自己敲下来、然后当成 ground truth"的句子（例见文末的表）。它们的共同特征是：**找不到机主的真实场景。**

## 逐条意图

### 1. 采集是唯一不可再生的东西

转写可重跑、纪要可重写，**录音没了这场会就没了**；"看起来在录、其实没录"最坑人。我们要：这种状态不许存在；界面的第一职责是让"采不到"不可能被忽略；宁可先保音频。
**推翻**：不推翻。这是底线。

### 2. 一张常驻的会议工作台

开完会想看那场转写好没、纪要出了没，也想翻以前那几场。我们要：左边"我这些会"，右边选中的那一场；切换工作区**不用重启服务**；同一时刻只有一场在录（硬限制）。
**推翻**：实际用下来从不回头看过去的会、也从不会后停留，"工作台"可以退化成"录音器 + 一个按钮"。

### 3. 一个工作区 = 一场会 = 一个目录，目录名由人起

目录名就是身份，AI 发明过"默认落点 + 按日期自动命名"、想改还改不动。我们要：**目录名就是这场会的名字**，软件不生成它、不改它、不解析它；日期语义写进目录**里面**的元信息文件；选择器可以替你建目录，但落点是你浏览的那层、名字是你亲手输入的那份，不清洗、不改写、不自动命名。
**推翻**：要让软件自动命名或自动挑落点，这条要重新谈。

### 4. 没有默认落点

"默认落点"一发明，启动扫最近一场、按日期命名、命令行必须手给路径全从它上面长出来。我们要：落点始终由你挑；列表由软件自己记，一份注册表住在软件配置目录里。
**推翻**：九成的会都在同一目录，可以加"记住上次那个目录"当选择器的**起点**——只是起点。

### 5. 删除工作区 ≠ 删内容

"删"这个字最容易出灾难。我们要：删除只是**从列表移除，文件一个字节不动**；还能"打开目录"收回；目录被移走的那一行显示"路径已不在"。
**推翻**：不推翻。真要"连文件一起删"，另起名字、二次确认。

### 6. 元信息归软件自己记，字段随便加

把元信息当"必须自洽的正式数据"，就会有人校验它、报错、甚至改结论。我们要：字段随便加（日期、起止、分了几段，以后参会人、声音样本……），**除了"实际录到的音频时长"一律不校验**；任何代码不许拿别的字段核对、报错、改结论。
**推翻**：某个字段真要**被程序当判据用**，必须在这份文档里点名，不许悄悄开始校验。
**已点名的字段**：人名表（`meeting_speaker_names.json`）会被程序读来**喂下一次出纪要的提示词**；程序对它只读、转述，读不出就当"没有确认过的名字"。

### 7. 权威长度 = 实际录到的音频时长

没有权威数，谁都能拿自己的数质疑别人。我们要：**实际录到的音频时长（不含暂停）是唯一权威**；墙钟跨度和空档时长只是附注。
**推翻**：不推翻，这是定义。

### 8. 暂停就是暂停：不录内容，写静音

"假暂停"会变成"我以为没录、其实偷偷录了"——那是信任问题。我们要：一个就叫**暂停**的按钮，语义老实（那一截往文件里写静音）；暂停状态在界面上极其显眼，跟"哪一路死了"一个级别。
**推翻**：确实需要"声音留着、只是不进纪要"，必须在界面上说破，**不能管它叫暂停**。

### 9. 一次段 = 一次录制；暂停和切源都不切段

整条链曾假设"一场会只录一次"，续接被砍掉，"音频比文本长"这类悬案来自这里。我们要：**段只表达"这场会录了几次"**；暂停、关某一路都是"那一路写静音"；两路永远时间对齐；续接 = 同一个工作区再录一段，时间洞在转写里留断口。
**推翻**：段太多导致对拍和使用变复杂，可以退成"一条连续流 + 段只是标记"。

### 10. MOSSTD 是可选的：会后是两个按钮，结束录音什么都不发生

MOSSTD 曾自动跑、还挂在纪要尾巴上，想停只能杀整个服务。我们要：工作台上**两个独立按钮**——「生成会后精细稿（走 MOSSTD）」与「生成纪要（把手上的稿子交给 DSH）」；**都不按就什么都不发生**；结束录音那一刻**不弹窗**。
**推翻**：MOSSTD 快到几分钟，可以重新把"先跑它"做成默认——但"能选"这条不推翻。

### 11. 两份稿子放在一起对拍

把会后那条叫"权威"会诱导人无条件信它，而实测**并不保证** MOSSTD 比会中模型好。我们要：给 DSH 的提示词**同时带两份**（会中稿一定有、会后稿不一定有），由它自己判断；界面标签平级（会中稿 / 会后稿）；「出纪要」按钮上必须一眼看出**有没有**会后精细稿。
**推翻**：反复实测某一方稳定更差，可以标"参考价值较低"，但不叫"权威"。

### 12. 进度看得见，而且是每个工作区自己的

会后要跑一小时，你得知道能不能去睡觉、跑到哪了。我们要：**每跑完一块就落一次盘**；界面上像会中转写那样往下刷、带进度条、可展开收缩；左边那一行的状态（空闲 / 正在录 / 会后跑着 / 等你动手）一眼可见。
**推翻**：不推翻。
**附**：不做全局进度条——进度是每个工作区自己的；全局只留一个"显卡忙不忙"（有一个模型开着就是忙）。

### 13. 打断要留痕迹，以后能重跑

杀掉就永远停在"在跑"，下次必须全重跑。我们要：能停；停完状态明确写"被打断"；以后能重新按按钮跑；开新会议时弹一句"启动新会议会打断会后总结，是否继续"。
**推翻**：不推翻。

### 14. ASR 那五个参数封死

这套值推了很久，作用之一是**防止 ASR 自己爆掉**（自循环、过拟合、一口气吐五分钟废话）；机主不在意一句话切三节还是四节，但极其在意模型炸掉。我们要：**任何节点都不许改那五个值**（段长 / 超时 / token / 周期上限 / 覆盖率），界面也不给入口。
**推翻**：只有机主本人明确要求调它时。

### 15. 设置要有界面（会中就能改），但不是什么都要

设备被占要当场换、服务商没 token 了要当场换模型，不该每次改配置文件重启。我们要：一个设置按钮 → 网页内小窗 → 确定写进 config。**放**：换设备、告警提示音、心跳频率、快速总结默认窗口、会中切模型（多套预设）。**不放**：ASR 那五个参数、会后用哪个模型、进会前的配置面板。
**推翻**：哪一样碍事就删。

### 16. 心跳问的是"你还在吗"

录音线程卡死了但 HTTP 还通——只看"HTTP 通不通"会漏掉"服务活着、录音死了"。我们要：界面按固定周期要一次心跳（1–60 秒可配）；**自动出总结的节奏不存在，也不会回来**（V1 那个"每 10 段 / 5 分钟一次"已被手动按钮取代）。
**推翻**：不推翻。

### 17. 告警要能一眼看见，但不许一惊一乍

一惊一乍的告警会让人把开关关掉，关掉之后真出事就没人知道——比没有告警更糟。我们要：致命级（某一路采不到、心跳失联）横幅 + 首发一声；提示级（转写落后之类）只上界面；"本次会不再出声"是会话级、不改那个持久开关。
**推翻**：门槛与抑制窗口的数值可以调。

### 18. 要不要做看意图，V1 只作参考

V1 的会中实时总结其实已经坏了，机主根本不在意；把"V1 有"当成"必须有"，会把没人用的东西搬过来，更糟的是把 V1 里"不做"的东西当成约束继承。我们要：V1 只用来问"这个你还要吗"；**要不要做，依据是这份文档里的意图**。
**推翻**：不推翻。

### 19. 工具型功能按"对验证有没有用"取舍

有些事机主本人不做，但 AI 改会后链路时，不用真开两小时的会就能验证；用"用户会不会用"去砍工具，等于捆住 AI 自己的手脚。我们要：命令行工具类功能的判据是**对验证有没有用**。
**推翻**：不推翻。

### 20. 不许在机主的机器上弄出他没想到的东西

某个节点曾直接从机主的耳机里放会议录音——没有预警、也没停下来问，当时他正在听音乐。这跟"偷偷录音"是同一类问题：机器在你的环境里做了你没同意的事，声音尤其冒犯。我们要：任何会影响机主环境的行为——**放音**、弹窗、抢设备、把显存占到别人用不了——动手之前都要说清；**放音默认不做**，要放也得先问。
**推翻**：机主明确要求"放出来听听"的那一次，就放。

### 21. 模型该用的时候拉起来，用完就关

在显卡里塞一个 4G 到 6G 的大模型"以防下次要用"是白占。我们要：**要用的时候才拉起来，用完立刻关掉**——会议开始拉会中模型、会后链开始拉会后模型；暂停、打断、终止、跑完，都当场结束。这条已定死，不需要谁再拍板。
**推翻**：不推翻。
